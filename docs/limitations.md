# Limitations



- Results primarily concern validation performance.

- Model thresholds were selected using validation data.

- Independent test-set success has not been established

  for the fine-tuned model.

- False-positive rate measures background pixels

  within defect-positive crops.

- Fine-tuning improves small-component detection

  while increasing false-positive regions.

- Industrial data and trained checkpoints are not

  publicly distributed.
